# commandes git

listes des commandes git

## git init
permet de transformer un repertoire normal en un repertoire git

## git add
permet de creer un fichier et de l'envoyer dans le stagging en attendant son enregistrement en local

## git commit
permet de confirmer la creation d'un fichier
son enregistrement en local

## git push
permet de transferer(pousser) un fichier(code) vers une solution logiciel(GITHUB, GITLAB, BITBUCKET..) afin d'etre enregistre en ligne

## git status
permet de lister les modifications a traiter
permet de verifier le statut du repertoire

## git log
permet de lister les modifications en localc
