# commandes git

listes des commandes git

## git init
permet de transformer un repertoire normal en un repertoire git

## git add
permet de creer un fichier et de l'envoyer dans le stagging en attendant son enregistrement en local

## git commit
- permet de confirmer la creation d'un fichier
- son enregistrement en local

## git push
permet de transferer(pousser) un fichier(code) vers une solution logiciel(GITHUB, GITLAB, BITBUCKET..) afin d'etre enregistre en ligne

## git status
- permet de lister les modifications a traiter
- permet de verifier le statut du repertoire

## git log
permet de lister les modifications en local

## git branch feature/
permet de creer une branche secondaire

## git checkout feature/
permet de se deplacer vers la branche secondaire

## git checkout -b feature/
permet non seulement de creer une branche secondaire, mais aussi de se deplacer vers celle-ci

## git pull
permet d'enregistrer en local les modifications qui ont ete fait directement en ligne sur github

## git rebase
- permet de transferer les modifications effectuées sur la branche mere vers une branche secondaire
- ces modifications sont enregistrées en dessous des modifications de la branche principale

## git merge
permet de transferer les modications effectuées sur une branche secondaire vers la branche principale
